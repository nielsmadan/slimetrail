# 2026-11-16 real all-agent attempt, 180-second deadline

Purpose: measure the local six-agent corpus through the same release CLI as the [synthetic baseline](2026-11-16-synthetic.md). Command: `timeout 900 python3 scripts/benchmark.py --real`, with the driver's default 180-second per-command deadline, 840-second total budget and five warm repetitions configured. Hardware/toolchain and binary SHA-256 match that baseline. The repository had no commit; no source mutations were made for this measurement.

[Aggregate evidence](2026-11-16-real-180.jsonl) records 29,581 files and 16,194,070,285 source bytes across the six resolved agent inventories. These are metadata counts of all files under the scanned roots, including companions and unsupported files, not parsed-session totals. No unreadable metadata paths were counted. One absent OpenCode sidecar was recorded; absence alone is not a source failure.

The capacity preflight passed: 279,467,151,360 bytes free versus a conservative 196,476,327,068-byte requirement (12 × source bytes plus 2 GiB). Continuous free-space monitoring remained in force. The cold all-agent index exceeded the 180-second subprocess deadline; the driver killed and reaped it and exited 2 with `TimeoutError`. At an aggregate-only progress check around 105 seconds, the private index was 936,411,136 bytes. There is no completed cold latency, session/entry count, final refresh diagnostic result, or warm-query measurement from this attempt. No latency extrapolation or coverage claim is made from partial index size.

Cleanup ran after the timeout and reported `index_exists: false`, `workspace_exists: false`; an independent glob count found zero benchmark workspaces immediately afterward. The source-containing index was removed. Query stdout would have been discarded, but no search phase was reached; only this aggregate record was retained.

This deadline was too short to establish real all-agent behavior. A separately recorded clean attempt with a 900-second cold deadline follows; this attempt is retained rather than reported as a successful baseline.
